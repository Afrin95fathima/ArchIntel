Phase 8 user flow: supervised modernization progress

Open Source tasks, choose the application and architecture version, then review the Supervised progress table. Each task shows its current state, unresolved blocker count, validation state/freshness, and suggested next action. Select a task to open its detailed workflow.

The board summarizes existing evidence to help a human decide what to do next. It does not run builds, change source, approve a patch, publish an architecture version, or advance a modernization wave. Continue to use the task's individual review and validation controls, and inspect the evidence before acting.
